# VAMIOS Bingo — Fully Corrected Starter

Demo/virtual-credit Bingo web app with React/Vite, Node/Express API, Telegram bot starter, shared TypeScript package, and GitHub Pages deployment.

## Deployment
- Frontend: GitHub Pages under `/vamios-bingo/`
- API: `https://vamios-api.onrender.com`
- CI: Node 22, npm workspaces

## Game rules in this starter
- Stakes: 10 / 15 / 25 / 50 demo credits
- Boards: 1–100, deterministic 5x5 cards
- 75 numbers, B/I/N/G/O ranges, center FREE
- 60-second waiting period, then number calls every 5 seconds
- Server-side Bingo validation
- 80% prize / 20% commission calculation

## Important
This is a demo/virtual-credit project. It is not a real-money gambling platform. Real-money operation requires applicable licensing and compliance, age and geo controls, KYC/AML, responsible-gaming controls, lawful payment processing, security, privacy, tax/reporting, and platform requirements.
